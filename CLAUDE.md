# Notes for Claude sessions

Read `CONTRIBUTING.md` before making changes: it has the rules for working alongside the other developer (pull first, branch per change, file ownership, no version bumps on branches, art handling).

The project lives under `GitHub upload/`:

- the addon: `GitHub upload/AzerothAlmanac/`
- what to work on and who has it: GitHub Issues and the project board (overview in `docs/ROADMAP.md`)
- what changed per version: `GitHub upload/CHANGELOG.md`
- what needs checking in game: `GitHub upload/docs/TEST_CHECKLIST.md`
- design record (rules, research, decisions): `GitHub upload/docs/DESIGN.md` (was `docs/TASKS.md`)
- current version and open points: `GitHub upload/STATUS.md`

At the start of a session, read this file, `CONTRIBUTING.md` and `STATUS.md`, and ask which issue is being worked on. Before committing, add the change to `CHANGELOG.md`, add anything that needs an in-game check to `docs/TEST_CHECKLIST.md`, and record any design decision in `docs/DESIGN.md`.
