Talent Planner data (Data\TalentData.lua, Data\TalentText.lua)

WoW Forever's talent trees and talent text come from talentsforever.com
(https://talentsforever.com), a fan-made WoW Forever talent calculator whose data is read from
the WoW Forever beta client's own files. Generated by tools\gen-talents-forever.js from
https://talentsforever.com/data.json (generated 2026-10-01, client build 1.60.1.70009).

Data from talentsforever.com (https://talentsforever.com). Changes made: converted to Lua tables
in Plus Everything's format (rows and columns from 0, prerequisites as indexes, spell IDs added
where a talent is unchanged from Classic). Game names, icons and tooltip text belong to
Blizzard Entertainment.
