## #31 Dungeon card: word-art dungeon names

**Want:** the dungeon's name as WoW-logo word art instead of plain text.

**Font:** LifeCraft (the zip you sent). dafont lists it as **donationware** by Eliot Truelove; the font file itself carries no licence text. Since the repo is public, the plan is to **not ship the font file**: we render the names into textures once, ahead of time, and credit the font in `AzerothAlmanac/Licenses/LifeCraft.txt`. A small donation to the author would square it. Say if you'd rather check with him first.

**Look (sample rendered 2026-10-08, `docs/art_source/WordArt_Sample.png`):** a gold gradient (pale gold at the top, deep amber at the foot), a bevel lit from the top left, a dark bronze outline and a soft drop shadow.

**Plan:**
- **`tools/wordart.py`** (beside `art_convert.py`) renders every dungeon and raid name:
  - names longer than about 14 letters on two lines ("Temple of / Ahn'Qiraj");
  - a thicker outline and less bevel for the small version, since at card size the fine detail disappears (checked in the sample);
  - packed several names to a 512 x 512 texture (`Media/DungeonNames_1.tga` ...), with each name's texture coordinates in a generated table (`Data/DungeonNames.lua`).
- **Where it shows:**
  - the Dungeons page cards (`UI/DungeonCard.lua`: the name on the plaque, today Morpheus in dark ink);
  - Wild Gambit's event card (the dungeon's name above the card, today Morpheus 15);
  - the dungeon's header on the Dungeons page (tab 2), larger.
- A dungeon with no word art yet (or Forever adds one) falls back to today's Morpheus text.
- New textures: full game restart. Re-run the tool for any new dungeon.

**Decided:** raids get a deeper red-gold, dungeons the bright gold.

## #36 Gathering: skill needed to gather

**Want:** each gatherable shows the skill level needed.

**Today:** there's no data on what a node needs; `rec.skill` is only *your* skill when you gathered it.

**Plan:**

- **Shown:**
  - Gathering list rows: "Herbalism 125" on the right, coloured for the current character like the game's skill-up colours (red: too low; orange, yellow, green, grey).

  - Map pin tooltips: the same line.

## #44 Bug: herbs show no icon on the Gathering page

**Cause:** a herb you've only *seen* (never gathered) has no loot, so its row falls back to the Herbs category icon, given as the name `Trade_Herbalism`. That name most likely doesn't load on this client (the code's icon check can't always tell), so the row draws blank. Ore nearly always has loot, so it shows the ore's icon. The map pins already handle this (they look up the node's loot in the hidden database), so pins show Peacebloom while the list is blank.

**Fix:**
- The list and the node's portrait use the same fallback as the map pins: the node's loot from the hidden database.
- The Herbs category icon gets a file ID first (`133939`, already used for the herb tracking button), with the name as a fallback; the same fix in the other four places that use the bare name (map pin kinds, milestones, People groups, the inventory window).
- Also fixes the blank Apprentice badge on herbs, which uses the same icon.
